How this page is wired

  • This GUI is a front end only — it calls the same Python modules as the terminal menu.
  • Results are computed live in Python and returned as JSON; nothing is hard-coded.
  • Charts are drawn in the browser from those numbers (CSS/SVG), so no plotting library is needed here.
  • Datasets come from data/; the editor lets you change them for a run without touching the file.

Command line, still available

python3 main.py            # terminal menu
python3 main.py --report   # rebuild report.pdf
bash scripts/test.sh       # 119 unit tests
python3 webapp/server.py   # this GUI

Stop the server with Ctrl+C in its terminal.
